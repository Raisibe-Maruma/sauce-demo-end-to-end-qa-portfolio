# SauceDemo End-to-End QA Portfolio

A complete Quality Assurance portfolio project for https://www.saucedemo.com using manual testing, API testing

## 📁 Project Structure

| Folder | Purpose |
| --- | --- |
| **test-plan/** | Test strategy, scope, and approach documentation |
| **test-cases/** | Manual test cases written for TestRail format |
| **api-tests/** | Postman collections and API test results |
| **bug-reports/** | Defect reports with steps to reproduce and evidence |

## 🛠 Tools & Skills Demonstrated

- **Manual Testing**: Test case design, exploratory testing, regression testing
- **API Testing**: Postman, REST API validation, JSON assertions  
- **Bug Tracking**: Jira-style bug reports with severity and priority
- **Documentation**: Clear test plans, test cases, and traceability
- **Git/GitHub**: Version control and portfolio organization
