# Bug Reports

This folder contains all defect reports found during manual and API testing of the SauceDemo application.

## How to Read This

Each bug is tracked with a unique ID: `BUG-001`, `BUG-002`, etc

| Bug ID | Severity | Module | Status |
| --- | --- | --- | --- |
| BUG-001 | Medium | Checkout | Open |
| BUG-002 | Low | Login | Closed |

## Bug Report Template

Each bug file follows this format:
- **Steps to Reproduce**
- **Expected Result**
- **Actual Result**
- **Environment**
- **Screenshot**

## Tools Used
- TestRail for test case management
- Jira/GitHub Issues for defect tracking
- Chrome DevTools for debugging
